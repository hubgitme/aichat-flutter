# 📱 ای‌چت — نسخهٔ نیتیو Flutter

اپ اندرویدی نیتیو (بدون WebView/مرورگر) برای پروژهٔ AICHAT: چت فارسی با
مدل‌های هوش مصنوعی از طریق بک‌اند Flask خودت (همان بک‌اند نسخهٔ وب).

## ویژگی‌ها
- چت با استریم (SSE) و دکمهٔ توقف؛ رندر مارک‌داون با بلوک کد (کپی + دانلود؛
  کدهای طولانی ≥۱۲۰۰ کاراکتر یا ≥۳۰ خط جمع‌شده نمایش داده می‌شوند)
- پیوست عکس (JPG/PNG) — در چت به‌عنوان `image_url` به مدل می‌رسد، در حالت
  تصویر به‌عنوان ورودی ویرایش استفاده می‌شود
- جست‌وجوی وب (دکمهٔ 🔍) با نمایش منابع
- خواندن خودکار لینک: اولین لینک پیام خوانده و به‌عنوان کانتکست به مدل
  داده می‌شود؛ اگر صفحه خوانده نشد، به مدل گفته می‌شود محتوا را نسازد
- حالت تصویر (تولید/ویرایش — شامل ویرایش JSON برای SenseNova) و حالت
  ویدیو (لینک قابل پخش)
- تاریخچهٔ محلی با تغییر نام، حذف، خروجی و بازیابی JSON
- همگام‌سازیِ سرتاسری رمزنگاری‌شده با نسخهٔ وب (همان پروتکل): کد
  همگام‌سازی ۲۰ حرفی، مشتق کلید با PBKDF2 و رمزنگاری AES-GCM؛ سرور فقط
  متن رمزشده می‌بیند

## راه‌اندازی
۱. بک‌اند Flask (نسخهٔ `aichat-sync-jsonedits`) را روی Vercel دیپلوی کن.
۲. اپ را نصب کن، به **تنظیمات** برو و وارد کن:
   - **اتصال:** آدرس بک‌اند (مثل `https://xxx.vercel.app`)
   - **مدل چت:** آدرس پروایدر، مدل و کلید API
   - **تصویر:** آدرس پروایدر، مدل، کلید، نوع اندپوینت و (در صورت نیاز) الگوی URL
   - **ویدیو:** آدرس پروایدر، مدل، کلید، مدت و الگوی URL
   - **سینک:** کد همگام‌سازی (همان کدی که در نسخهٔ وب استفاده می‌کنی)
۳. هیچ پروایدر، مدل یا کلیدی در اپ هاردکد نشده است — همه را خودت وارد می‌کنی.

## همگام‌سازی با نسخهٔ وب
کد همگام‌سازی در نسخهٔ وب و این اپ یکی است. از روی کد، با PBKDF2
(۱۰۰٬۰۰۰ تکرار، salt ثابت `aichat-sync-v1`) یک کلید AES-GCM و یک شناسهٔ
۶۴ حرفی مشتق می‌شود. گفت‌وگوها قبل از ارسال gzip و رمز می‌شوند و حذف‌ها
با سنگ‌قبر منتقل می‌شوند. عکس‌های base64 همگام نمی‌شوند (فقط علامت
می‌خورند) و دستگاهی که عکس را دارد، نسخهٔ خودش را نگه می‌دارد.
سازگاریِ رمزنگاری با بردارِ تستِ `test/sync_vector.json` بررسی می‌شود که
با پیاده‌سازیِ واقعیِ JS ساخته شده است (`tool/gen_sync_vector.mjs`).

## ساخت APK با GitHub Actions
۱. این پوشه را در ریپوی `hubgitme/aichat-flutter` پوش کن.
۲. در تب **Actions** ورک‌فلوی «Build Flutter Android APK» را اجرا کن
   (یا روی main پوش کن).
۳. از صفحهٔ همان اجرا، APK را از Release با تگ `v1.0.0` دانلود و روی گوشی
   نصب کن (نصب از منابع ناشناس را فعال کن).

پوشهٔ `android/` در CI با `flutter create` ساخته می‌شود و در ریپو نیست.
نسخه: `1.0.<run_number>` و فقط arm64.

## امضای APK
APK با کی‌استور PKCS12 داخل `keystore/` امضا می‌شود (ساخته‌شده با
OpenSSL؛ CN=AICHAT؛ رمز `aichat`). مثل نسخهٔ کریپتولنز، این کی‌استور
عمومی است و فقط برای همین اپِ شخصی کاربرد دارد — اگر اپ را عمومی
می‌کنی، کی‌استور را عوض کن.

## ساختار
```
lib/
├── main.dart            # ورود برنامه، تم و RTL فارسی
├── models.dart          # Conversation / ChatMessage / Source
├── settings.dart        # تنظیمات (SharedPreferences)
├── api.dart             # کلاینت بک‌اند: چت SSE، جست‌وجو، لینک، تصویر، ویدیو، سینک
├── sync_crypto.dart     # PBKDF2 + AES-GCM + gzip (پورت js/sync-crypto.js)
├── sync_engine.dart     # موتور همگام‌سازی (پورت js/sync.js)
├── store.dart           # ذخیرهٔ محلی گفت‌وگوها و سنگ‌قبرها
├── utils.dart           # استخراج URL، کد طولانی، پنجرهٔ تاریخچه، کانتکست‌ها
└── ui/
    ├── home_page.dart       # چت + دراور گفت‌وگوها + ارسال/توقف
    ├── settings_page.dart   # تنظیمات گروه‌بندی‌شده (Material 3)
    └── code_block.dart      # بلوک کد مارک‌داون (کپی/دانلود/جمع‌شدن)
test/
├── sync_vector.json         # بردار تست سازگاری با JS
├── sync_crypto_test.dart    # مشتق کلید + رمزگشایی بلاب‌های واقعی JS
├── sync_engine_test.dart    # سناریوهای همگام‌سازی با سرور جعلی
├── api_payload_test.dart    # بدنهٔ درخواست‌ها + پارس SSE
└── utils_test.dart          # URL، کد طولانی، تاریخچه، کانتکست‌ها
tool/gen_sync_vector.mjs     # ساخت دوبارهٔ بردار تست از روی JS واقعی
```

## وضعیتِ تأیید
- سازگاریِ رمزنگاریِ سینک با پیاده‌سازیِ واقعیِ JS بررسی شده است
  (PBKDF2، AES-GCM، gzip — بردار تست در `test/sync_vector.json`).
- بیلد APK و تست‌های Flutter فقط در CI قابل اثبات‌اند (روی این ماشین
  Flutter نصب نیست) — اولین اجرای ورک‌فلو آن‌ها را تأیید می‌کند.
